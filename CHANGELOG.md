# Changelog

Initial Shrinkcage distribution: local agent connector center, metadata-only session explorer for Codex CLI, Claude Code and Gemini CLI; retained Headroom, RTK and Serena monitoring; approved local folder settings; portable startup, packaged CLI, privacy controls, regression tests and cross-platform CI.

Local file formats are version-dependent. See the connector compatibility notes and validation matrix before relying on a new CLI release.
